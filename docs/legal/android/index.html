Mycena for Android

Communication when the network fails. Technical preview, not on Google Play yet.

Download the app (APK)

Newest preview from GitHub Releases

  1. Tap Download above and wait until the file has finished (about 100 MB, Wi-Fi recommended).
  2. Open the downloaded file from the notification or from the Files / Downloads app.
  3. Android asks whether your browser may install apps: tap Settings, switch on Allow from this source, then go back.
  4. Tap Install. If Play Protect warns about an unknown app, tap More details → Install anyway. The preview is signed with a test key, which causes this warning.
  5. Open Mycena and allow Bluetooth and nearby-devices access so phones can find each other.

Needs Android 8 or newer. To update, install a newer file over the old one; your data stays. To check the download, compare it with SHA256SUMS.txt on the release page.

Auf Deutsch

  1. Oben auf Download tippen und warten, bis die Datei fertig ist (ca. 100 MB, am besten im WLAN).
  2. Die Datei über die Benachrichtigung oder die App Dateien / Downloads öffnen.
  3. Android fragt, ob der Browser Apps installieren darf: Einstellungen antippen, Aus dieser Quelle zulassen einschalten, zurückgehen.
  4. Installieren antippen. Warnt Play Protect vor einer unbekannten App: Weitere Details → Trotzdem installieren. Die Vorschau ist mit einem Testschlüssel signiert.
  5. Mycena öffnen und Bluetooth sowie „Geräte in der Nähe“ erlauben.
